# 누가샀나 수익 구조 — 광고 말고 (2026-09-19 밤 조사·제안)

> JJ 2026-09-19 밤: "이제 이 채널을 운영하면서 수익화를 만들어내는 구조를 찾아서 본격적인 수익화 채널로 이동해야 해." "유튜브 광고로 버는 거 말고 다른 방식으로 — 쿠팡파트너스, 구독시스템, 외주 등등."
> 조사 세 갈래(벤치마크 채널 12곳 · 한국 법·규제 · 제휴/구독/외주 시장)를 합친 것. 표기: [확인] 공식·기사 원문 확인, [추정] 2차 자료·계산·일화, [제안] 우리 안. 법 부분은 조사이지 법률 자문이 아니다.

## 0. 결론

- **지금 규모(구독 35 · 28일 조회 1.6만)로는 청중 크기에 비례하는 수익 — 제휴·구독·협찬 — 은 한 달 몇만 원 수준이다.** 사관학교형 유료 구독(1,350명 × 3,900원 ≈ 월 500만)은 청중이 수십 배 커진 뒤의 이야기.
- **당장 돈이 되는 건 우리가 이미 만든 것을 파는 일** — 매일 데이터 → 대본 → AI 음성 → 차트 영상 → 업로드를 돌리는 제작 체계와 JJ의 개발 역량. 크몽 숏폼 편당 평균 13만 원[확인], 위시켓 대시보드 외주 800만~2,000만 원[확인].
- 그래서 구조는 **채널 = 쇼룸·유입구, 돈은 세 줄:** ① 외주(지금) ② 구독(3~6개월, 무료로 모은 뒤) ③ 제휴(작게, 지금부터).

```
누가샀나 유튜브 · Threads  (매일 발행 = 신뢰 + 포트폴리오)
 ├─ 프로필·설명 "데이터 영상 자동 제작 문의"  ──→ ① 외주: 제작 대행 · 자동화/대시보드 개발
 ├─ 같은 대본을 글로(블로그 · 무료 뉴스레터)   ──→ ② 유료 구독 '주간 돈의 흐름 노트'
 └─ 블로그 · Threads 투자서 소개 글            ──→ ③ 쿠팡파트너스
```

## 2. ① 외주 — 지금 돈이 되는 줄

**무엇을 파나 [제안]**
1. **데이터 숏폼 정기 제작** — 고객의 데이터로 매일/매주 자동 영상(대본·음성·차트·자막·썸네일·업로드 문안까지). 누가샀나가 2주 넘게 평일 매일 17시에 나간 것이 곧 포트폴리오.
2. **자동화·대시보드 개발** — 수집 → 계산 → 화면(Remotion·웹) 파이프라인을 고객 업무에 맞춰 구축.

**누구에게 [제안 + 근거]**
- 금융: 소형 증권사·운용사·핀테크·IR 대행사. 대형 증권사는 자체 제작(삼성 300만·미래에셋 236만·NH 224만 구독, 한투는 AI 시황 '지금 시장은'을 사내에서 만들어 한 달 만에 1,000만 회)[확인] — 대형사에 '자동 시황'을 파는 건 어렵다.
- 금융 밖: 데이터가 매일 바뀌는 업종 — 부동산 시세·분양, 농수산 시세, 환율·유가(여행·물류), 공공데이터 홍보(지자체) 등. KRX 데이터를 안 쓰니 재배포 문제도 없다.
- 개발 외주: 위시켓 '주식 재무 대시보드' 800만/40일(2021), '데이터 모니터링 대시보드' 2,000만/30일·지원자 50명(2025-05)[확인].

**값 [제안]** — 크몽 숏폼 편당 평균 13만(최저 2만~최고 34만)[확인], 반면 '쇼츠 자동 생성 프로그램 9,000원에 70편' 같은 가격 붕괴도 있다[확인]. 우리는 단가 경쟁이 아니라 **정확한 데이터 + 매일 자동 + 브랜드 맞춤 화면**으로 월 정액(평일 매일 1편 기준 100~200만 원대)과 구축비(300만~800만 원대)를 제안가로 시작해 반응을 본다.

**지킬 것**
- 사업자등록(업종은 세무사 확인 — 1인 미디어 940306 면세 / 소프트웨어·영상 제작 외주는 별도 업종일 수 있다)[확인: 국세청 업종코드].
- 상장사 IR 영상을 받으면 그 회사는 우리 채널 '기업 해부'에서 다루지 않거나 이해관계를 밝힌다 — 채널 신뢰가 자산이다.
- 고객 영상을 우리 채널에 올리면 제목·첫 부분에 '유료광고' 표시(공정위 지침, 2024-12 개정)[확인].
- 'AI 쇼츠 자동화 강의'로 팔지는 않는다 — KBS 추적60분(2026-02·04)이 고액 AI 쇼츠 강의를 다뤘고 금융 채널 신뢰를 깎는다[확인]. 서비스(대행·구축)로 판다.

## 3. ② 유료 구독 — 무료로 모은 뒤

**형태 [제안]:** 매일 원자료 표가 아니라 **'주간 돈의 흐름 노트'(주 1회 글 + 그림 몇 장)** — 그 주 외국인·기관·개인이 어디서 빠져 어디로 갔나, 뉴스와 맞물림, 다음 주 확인할 숫자. 우리 영상과 같은 선(추천·전망 없음).
**플랫폼:** 네이버 프리미엄콘텐츠(수수료 8% + 결제 2.64%, 45세 이상에게 익숙)[확인] 또는 스티비(자체 수수료 0, PG 3.2%+VAT, 월 8,900원 요금제 필요)[확인]. 자체 웹 결제는 '주식/증권정보' 업종이 PG 심사에서 막힌다는 말이 있다[추정].
**값:** 월 3,900~4,900원(프리미엄콘텐츠 보통 월 1만 원 이하, 사관학교 3,900원)[확인].
**순서:** 무료(블로그·무료 뉴스레터, 쇼츠 설명·Threads 에서 유입) 2~3개월 → 무료 구독자 수백 명 → 유료 전환.

**법·데이터 — 돈 받기 전에 끝낼 것**
- **유사투자자문업:** 유료회원제로 투자판단을 조언하면 신고 대상, 광고 수익·자발적 후원만이면 불필요(금융위 법령해석 2021-06-01)[확인]. 수급 숫자와 뉴스 사실만이면 '판단'이 아닐 여지가 크지만, 유료 글에 "외국인·기관이 산 종목"과 해석을 붙이면 판단 제공으로 볼 위험[추정]. → **안전하게 가려면 신고**(금융투자협회 사전교육 8시간·87,000원, 5년 유효)[확인] 또는 금융위 법령해석을 먼저 받는다. 신고하면 광고에 '유사투자자문업자'·원금손실 가능성 문구가 필수(2025년 검사 105개사 133건 적발)[확인].
- **단방향만:** 유료 회원과 댓글·채팅으로 의견을 주고받으면 투자자문업 '등록'(법인·자본금) 대상(2024-08-14 개정)[확인] → 댓글 끔, 단톡방 없음.
- **데이터:** KRX 정보는 사전 허락 없는 배포 금지(KRX 약관 12조), 코스콤 정보이용계약 필요(실시간 기준, 장 마감 확정 수급에 적용되는지는 불확실), 증권사 API 약관은 '개인 업무 한정·제3자 제공 금지'가 흔함(한투 사례, **키움 원문 미확인**)[확인/불확실]. 무료 영상에서 몇 숫자를 말하는 건 언론 인용 수준이라 위험이 낮지만, 유료 상품에 표를 싣는 건 재배포 → **키움·코스콤에 서면 문의 후 시작.**

## 4. ③ 쿠팡파트너스 — 작게, 지금부터

- 수수료: 가이드 원문 "거래액의 3%", 카테고리별 차등(가전 약 1%)[확인/추정]. 월 1만 원 넘어야 지급(익익월 15일), 누적 15만 원 넘으면 채널 심사 후 최종 승인[확인].
- **쇼츠 설명·댓글 링크는 못 누른다**(유튜브 공식)[확인] → 링크 자리는 **Threads 답글 · 네이버 블로그 · 유튜브 채널 링크**.
- 상품: **투자서.** 예스24 2026 상반기 투자·재테크 도서 +44.5%, 국내주식 투자서 약 +277%, 50대 구매 +346%[확인] — 우리 시청자(45세 이상 76%)와 맞는다.
- 규칙: 공개 문구 "이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다." — 제목·첫 부분, 줄임·흐림 금지[확인]. **프로그램으로 양산한 글·링크만 있는 글은 페널티**[확인] → 자동 생성 대본에 링크를 붙이지 않는다. 손으로 쓴 소개 글(예: 기업 해부 편과 이어지는 책 한 권)에만.
- 기대치: 지금은 월 0~3만 원[추정: '방문 1만 → 9천 원' 일화]. 블로그 유입이 커지면 같이 큰다.

## 5. 하지 않는 것 (위험이 이득보다 크다)

| 수급 데이터 대시보드·원자료 판매 | 코스콤 계약 + 증권사 약관 허락 없이는 재배포[확인] |

| 'AI 쇼츠 자동화' 강의 | 평판 위험(KBS·동아 보도)[확인] |

## 6. 할 일

**JJ만 할 수 있는 것(계정·본인 인증·신고는 내가 하지 않는다)**
1. 사업자등록 — 업종(940306 1인 미디어 / 외주용 업종)은 세무사 확인.
2. 크몽·위시켓(외주), 쿠팡파트너스, 네이버 블로그·프리미엄콘텐츠(또는 스티비) 가입.
3. 유사투자자문업 신고 여부 결정(구독을 할 거면 권함).

**내가 바로 할 수 있는 것**
1. 외주 포트폴리오: 금융 밖 데이터로 샘플 영상 2~3편(공공데이터 — 재배포 문제 없는 것) + 서비스 소개 한 장(무엇·얼마·기간).
2. 대본 → 네이버 블로그 글 초안 변환기(링크 없는 정보 글, 손으로 다듬어 올림).
3. '주간 돈의 흐름 노트' 0호 견본(무료판) — 법 선을 지킨 틀.
4. 키움(오픈 API 상업적 이용)·코스콤(정보이용)·금융위 법령해석 요청 문의문 초안.
5. 쿠팡 투자서 소개 글 틀(공개 문구 포함).
