A4 (M-1) **이어짐을 실제로 말한다**: `continuity().others_top_same_days>=2` 면 두 종목 문장은 "오늘도 그 두 회사입니다. {N}일째, {share}%."(3벌) 로. 자사주 설명은 `said_within(d,"자사주",3)` 이면 **동격 한 마디만**("기타법인, 자사주입니다." / "이름은 기타법인, 속은 자사주." / "자사주 몫입니다.") — 긴 설명 후보는 전부 제외.
A5 (M-3) 기타법인 N일째가 자료 첫 편까지 닿으면(N == 이력 편 수) "자료가 있는 {N}편 내내" 대신 **"9월 들어 매일"**(첫 편이 같은 달) 또는 "{N}일째 이상"으로. `continuity` 가 `others_buy_days_capped` 를 주면 그걸 쓴다(script_memory 담당이 추가).
A6 (M-2) S6 둘째 관측값 회전: `promise_days>=2`(같은 질문을 이틀 이상) 면 기타법인 선 대신 다른 후보(유입 업종 이틀째 / 코스닥 외국인 방향 / 기관 순매도 N일째)를 먼저 고른다. S6 문장 틀(내일은 … 봅니다 / 또 하나 / 지켜온 선 / 이벤트 / 시그니처 앞 문장)은 각 4벌 이상, 전날과 같은 틀 금지(script_memory.pick).
A7 (M-4) S5 콜백은 **계산**이다: 훅의 두 숫자로 "처음의 {a}, {b}의 {비율}입니다" / "{a}은 {b}의 절반이었습니다" / "{a}와 {b}, 차이가 {diff}입니다" 중 데이터에 맞는 것. "그 숫자의 답이 이겁니다" 류 빈 문장 삭제.

F3: "하루 사정이면 내일 끊깁니다 / 방향이면 내일도 같은 손입니다". F4(새 돈 vs 회사 예산): 조건은 **출처**로: "기타법인 순매수에서 두 회사 몫이 절반 아래로 내려가는 날"(others_top share < 50%) — 크기 비교 조건 삭제. 뒤집히는 조건은 **하나**(L-3).
