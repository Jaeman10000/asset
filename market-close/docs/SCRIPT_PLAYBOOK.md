## 1. 한 줄 원칙

> **돈이 어디로 움직였는지를 데이터로 세어서 보여주고, 내일 그 말이 맞았는지 같은 자리에서 확인한다.**

풀어 쓰면 세 가지다.

1. **세어서 말한다.** 우리가 파는 건 의견이 아니라 체결 숫자다. 키움·거래소 실시간 수급, 장중 스냅샷, 일별 누적이 원자료다. 근거 없는 문장은 빼고, 근거 있는 숫자는 화면에 같이 찍는다.
2. **주어는 사람이다.** 채널 이름이 '누가샀나'다. 제목과 첫 문장의 주어는 **수급 주체**(외국인·기관·개인·기타법인)이거나 **돈**이다. 날짜도 지수도 주어가 될 수 없다.
3. **기록을 남긴다.** 예고 → 다음 날 검증(ledger)이 우리 유일한 반증 가능 자산이다. **맞은 날과 틀린 날을 같은 형식으로 말한다.** 맞은 날만 말하면 기록이 아니라 홍보가 된다.

이 세 가지를 깎아먹는 기법은 조회수가 오르더라도 쓰지 않는다. 판단 기준: *"이 문장을 내일 데이터로 반박당하면 우리가 손해인가, 아니면 그게 바로 다음 편 소재인가."* 뒤쪽이면 쓴다.

### 계산식 (모든 예산의 근거)
```
초 = 글자수 / 7.2 + 0.4 × 장면수      # CPS=7.2는 edge-tts InJoon +20% 실측
평일 5장면: 790자 → 109.7 + 2.0 = 111.7초 (목표대 안쪽)
주말 7장면: 1,230자 → 170.8 + 2.8 = 173.6초 (한도 175초)
```
**3분을 넘으면 쇼츠 피드에서 빠진다.** 길이는 취향이 아니라 유통 조건이다. 글자를 늘려야 하면 다른 문장을 지운다.

**계산식은 어림이고, 실측이 기준이다.** TTS가 `2.3조`를 `2조 3천억`으로 풀어 읽기 때문에 조·억이 많은 날은 실측이 계산보다 **5~8초 길다**. 반드시 `run_day.py <날짜> --stage=tts` 로그의 '총 N초'로 확인한다.

**길이는 목표가 아니다(JJ 2026-09-14).** "2분 넘어도 되고 3분이 되도 상관없다. 어차피 볼 사람들은 보고 나간다. 짧아서 끝까지 본다고 해서 이게 좋은 영상이 될 수는 없다. 구독자가 늘려면 그만큼 가치 있는 정보를 줘야 한다." 지켜야 할 선은 **3분 하나뿐**이고, 그 아래에서는 할 말이 있으면 한다. 대신 **끝까지 보게 만드는 장치를 곳곳에 시스템으로 심는다**(§3-1 트리거).

### 일요일 미국편의 단일 규칙
미국 소재를 **미국 소재로 팔지 않는다.** 제목에 한국 토큰(종목·주체·창구·코스피)이 최소 1개, 그리고 **훅 마지막 문장에서 "마지막에 국장 수급으로 확인한다"를 예고**한다. 실제 연결은 마지막 장면(uw6)에 그대로 두되, **전환 예고 지점을 대본 90%에서 5%로 당긴다.** 근거: 미국 단독 제목은 연령 보정 4구간 전부에서 중앙값 이하로 나온 유일한 음의 신호다(히트율 1.0%, 기준선 2.1%).

1. **훅 첫 화면을 말에 맞춰 연다** — 이름 → 금액 → 대비 줄. 0프레임에 다 찍으면 이탈이 가장 큰 첫 5초가 정지 화면이 된다.

4. **s5에서 지난 편 약속을 전부 회수한다** — 금요일 편(ledger) + 토·일 주간편(`weekend_watch.py`). 같은 약속이면 합친다.
5. **마지막에 화면을 한 번 리셋하고 묻는다** — 가장 많이 빠져나가는 자리다.

## 4. 훅 규칙

### 4-1. 절대 수치
- **첫 물음표: 평일 ≤5초(≤36자), 주말 ≤6초(≤43자).** 현재 우리는 평일 9.2초, 토 8.6초, 일 14.2초다 — 전부 위반.
- **훅 전체 길이: 평일 60~80자(8~11초), 주말 60~100자.**
- **훅 숫자: 총 2개, 첫 문장 1개.** 일요일 [uw0]은 현재 7개다.
- **훅 질문: 정확히 1개.** 나머지 질문은 s2 이후 사슬에서 쓴다.

### 4-2. 첫 문장 유형 (H01~H06) — 요일마다 돌린다
최근 3편에서 쓴 유형은 제외하고 고른다. `out/<date>/kr/props.json`에 `hook_id`를 남긴다.

| **H01** | 빈칸 질문 | 오늘 외국인이 내놓은 2조 3천억, 누가 받았을까요? | 한 주체의 순매도가 그날 최대일 때(기본형) |

### 4-3. 훅 뒤 첫 장면 — 리셋 규칙
훅에서 던진 질문은 **다음 장면 첫 문장에서 바로 답한다.** 훅 내용을 다시 설명하지 않는다.
- 평일 좋은 예(유지): `[s0]` "누가 이 물량을 받았을까요?" → `[s2]` "가장 많이 산 쪽은 개인입니다."
- 일요일 나쁜 예(고칠 것): `[uw0]` "사흘 내리 빠졌다가 금요일 하루에 되돌렸습니다" → `[uw1]` "화요일부터 목요일까지 사흘 내리 빠졌습니다" ← **같은 말 반복.** 첫 문장을 지우고 금요일 장면으로 바로 들어간다.

### 4-4. 쓰면 안 되는 훅
| 금지 훅 | 이유 |
|---|---|
| 날짜·회차로 여는 훅 ("오늘 9월 11일 국장 마감입니다") | 하위권 표지(제목군 25%). 유통기한이 그날로 끝난다 |
| 호명 ("여러분", "구독자님") | edge-tts는 호명에 억양을 못 실어 낭독체가 된다. 친밀감이 아니라 이물감 |
| 집중 요청 ("딱 1분만 집중해 주세요") | 155자·21.6초 = 평일 예산의 18%. 우리는 화면 카드가 그 일을 한다 |
| 자격 증명 ("직접 세어 왔습니다", "밤새 뜯어봤습니다") | 화자가 AI다. 1인칭은 금지어이고 주어 없는 노동 자랑은 매일 같은 자리에서 상투구가 된다. 신뢰는 **카드 하단 고정 라벨**로 낸다 → `자료: 장 마감 직후 수급 원자료 · 16:30 집계` |
| 시청자 무지 확인 ("아십니까?", "모르셨죠?") | 합니다체에서 훈계조가 된다. 빈칸은 시청자의 무지가 아니라 **오늘 장부의 공백**이다 |
| 손실 회피 ("모르고 버티면 크게 물립니다") | 공포로 클릭을 사는 방식. 금지어 검사와도 충돌 |
| 권위자 지목 ("파월이 콕 집은") | 발언은 누구나 받아쓴다. 우리 우위가 0인 경기장 |
| 로드맵 ("오늘은 세 가지를 보겠습니다") | 3분에서 목차에 10~15초는 블록 하나 반. 우리는 질문 사슬로 잇는다 |

## 5. 전개 규칙

### 5-1. 블록 구조
- 평일 전개부는 **정확히 3블록**(s1/s2/s3), **블록당 150~200자**, 블록 간 편차 50자 이내.
  현재 20260911은 s2가 320자(44초), s3이 108자(15초)로 깨져 있다.
- **각 블록은 [숫자 2줄 + '그래서 무슨 뜻' 1줄]로 닫는다.** 해석을 마지막 블록으로 몰지 않는다.
- **'내일·월요일'이라는 말은 s5에서 처음 나온다.** 전망은 마지막 블록 전용.
- 정보를 추가하려면 **새 블록을 만들거나 버린다.** 기존 블록에 "게다가·심지어·여기에"로 붙이지 않는다(하위권 지문: 상위 0.19/분 vs 하위 0.41/분).

### 5-2. 질문 사슬 만드는 법
1. **질문은 블록 경계에만.** 평일 전개부 질문 = 2개(블록1→2, 블록2→3). 블록 한가운데 질문은 경계로 올린다.
2. **질문 문장에는 숫자를 넣지 않는다.** 숫자는 답 문장이 갖는다.
3. **질문 다음 1문장 안에 답이 온다.** 답 없는 수사의문문 금지.
4. **앞 블록의 답이 다음 질문을 낳아야 한다.** 답이 새 공백을 만들지 못하면 그 블록은 자리를 잘못 잡은 것이다.
5. 질문 총량 상한: **평일 4개(훅 1 + 경계 2 + 마무리 전 1), 주말 6개.** 우리는 이미 1,000자당 5.3개로 경제사냥꾼 쇼츠(1.5개)의 3.5배다. **더 넣지 않는다** — 질문이 흔해지면 '답을 들으러 남는' 힘이 사라진다.

### 5-4. 숫자를 이해시키는 법
숫자를 늘리는 게 아니라 **줄이고 해석을 늘린다.**

| 항목 | 현재(평일 20260911) | 목표 |
|---|---|---|
| 1,000자당 숫자 | 18.5개 | **11개 이하** (평일 대본 기준 총 9개 이하) |
| 숫자 문장 중 3문장 안에 '뜻/셈'이 붙는 비율 | 30% | **50% 이상** |
| 편당 배수 표현 | 0회 | **1~2회** |
| 앵커 없는 금액 | 3주체 전부 | **0개** |

**앵커 강제 규칙**: `jobs/compute.py`에서 모든 수급 금액에 앵커 필드(`5일평균 대비 배수` / `전일 대비` / `20거래일 내 순위`)를 붙이고, **앵커가 없는 숫자는 대본에서 탈락시킨다.** 이게 우리가 그들을 이길 수 있는 유일한 자리다 — 비교 앵커는 조회 상·하위를 전혀 가르지 않은 '기본기'인데(2.49 vs 2.51/분), 그들은 손으로 붙이고 **우리는 계산해서 매일 붙일 수 있다.**

극값은 **반드시 집계 구간을 명시한다.** "역대 최대"(과장) → "20거래일 가운데 가장 큰 하루 순매수"(측정값). 구간이 붙는 순간 반박이 불가능해진다.

## 6. 마무리 규칙

### 6-1. 순서 고정 (평일 s5 ≤245자 + 끝 멘트 37자)
```
① 콜백·결과  →  ② 왜 보는가  →  ③ 판단 기준  →  ④ 전적  →  ⑤ 내일 하나 + 구독  →  ⑥ 고정 끝 멘트(37자)
```
장부 콜백이 없는 날(전날 예고가 판정 불가였던 날)은 ①②③④를 통째로 빼고 **'A가 아니라 B' 결론 한 줄(≤90자)**로 대신한다.
`jobs/qa_script.py`에 `CLOSE_MAX = {"day":285, "kr":215, "us":215}`를 넣고 `scenes[-2:]`의 글자수를 검사한다.

### 6-2. ① 결론 — '그래서 무슨 뜻'을 붙이는 법
결론은 요약이 아니라 **판단 한 줄**이다. 형태는 **'A가 아니라 B'** 재정의로 고정한다.

> 오늘 외국인이 판 2조 3천억을 받은 쪽은 개인 한 곳이 아니라, 자사주로 잡히는 기타법인까지 둘이었습니다. (57자·7.9초)

- 선언문("오늘 수급을 한 줄로 줄이면 이렇습니다." 22자)은 **주 2~3회만**, 3~4종을 돌린다. 매일 고정하면 `qa_script.mask()` 뼈대 중복 검사에 매일 걸린다.
- **결론 안의 숫자는 최대 1개, 그리고 반드시 앞에서 이미 말한 숫자의 재언급이다.** 새 숫자 금지.
- 결론 앞뒤로 ledger 집계 문장("세 번 확인했고 한 번 이어졌습니다")을 붙이지 않는다 — 그건 **주 1회**만, s4에서.

### 6-3. ② 내일 한 줄 — 다음 영상으로 잇는 법
- **확인점은 정확히 1개.** 2개 이상이면 시청자 머릿속에서 숙제 목록이 되고, 그게 하위권 습관이다.
- 그 1개는 **반드시 ledger에 기록되어 다음 날 검증 대상이 된다.**
- **양방향 조건 분기(T19)는 평일 주 1회(금요일)만.** 주말 두 편에는 **항상** 넣는다(현재 w6은 한쪽만, uw6은 분기 자체가 없다 — 둘 다 반대 가지를 채운다).
- 어시스트 문장에는 **종목명을 쓰지 않는다**(`assist_ok`가 막는다). 업종어(반도체·메모리)로 바꾼다.
- 지수 목표 레벨("6,950을 지키면 7,050이 열립니다")은 검사를 통과해도 **쓰지 않는다.** 레벨 대신 **수급 연속일수**로 말한다.

> 월요일에 볼 건 하나입니다. 외국인 순매도가 나흘째 이어지는지입니다. (38자·5.3초)

### 6-4. ③ 구독 한 줄
- **평일**: 구독 한 줄만. 좋아요·알림·댓글 요청은 **전부 넣지 않는다.**
  > 기록이 쌓이는 게 도움이 되면 구독해 두십시오. (26자·3.6초)
- **토·일**: 같은 구독 한 줄 + 주기 한 줄.
  > 이번 주 수급은 토요일에 한 번에 묶어 보여드립니다. (29자·4.0초)
- 평일→토요일 주간결산 유도는 **주 1~2회(수·금)만.** 매일 넣으면 틀 반복이다.
- 알림설정 요청은 어느 편에도 넣지 않는다. 주 1회 시청자에게는 '토요일'이라는 요일이 알림을 대신한다.

### 6-5. ④ 고정 끝 멘트 (한 글자도 바꾸지 않는다)
- 평일: `누가샀나였습니다. 국장 마감은 매일 저녁 5시에 올라옵니다.`
- 토: `누가샀나 주간 결산이었습니다. 평일엔 매일 저녁 5시에 국장 마감이 올라옵니다.`
- 일: `누가샀나 미국 주간 결산이었습니다. 평일엔 매일 저녁 5시에 국장 마감이 올라옵니다.`

> **구현 주의**: 구독 고정문과 끝 멘트를 넣는 순간 `qa_script.py`의 뼈대 중복 검사가 매일 "2개 겹침"으로 잡는다. `mask()` 비교 대상에서 **끝 멘트·구독 두 줄을 제외하는 예외**를 같이 넣는다.

### 6-6. BONDING 처리
`narrate.py`의 BONDING 5줄("같이 증명해 가겠습니다" 등)은 **평일에서 뺀다**(585행에서 s5 끝에 붙는 것). 마무리에서 30~40자를 확실히 뺏는 데 비해 상·하위 차이가 없는 약한 패턴이다. 소속감은 문장이 아니라 ledger 기록으로 만든다. **주말 편에만 남긴다.**

## 8. 제목·태그 규칙

### 8-1. 제목 패턴 (5개 고정)
```
P1  {주체} {금액} {동사}, {받아 간 곳|판 쪽}          ← 기본형
P2  {주체}가 {금액} {동사}한 날, {대비되는 사실}
P3  {N}일 내내 {동사} 곳                              ← 연속성
P4  어제 짚은 그 흐름, 오늘 수급으로 확인했습니다      ← ledger형(주 1~2회)
P5  {미국 사실}, {한국 주체·종목이 선 쪽}              ← 일요일 전용
```

### 8-2. 하드 규칙
1. **주어는 수급 주체.** 종목명은 목적어 자리에만, 그리고 **그날 유일했던 사실일 때만**(자사주 매입 / 업종 내 혼자 반대 / 연속 일수 최장).
2. **물음표로 닫는다.** ~~명사형으로 닫는다~~ — 이 규칙은 폐기됐다(2026-09-13). JJ가 직접 고친 제목 두 건이 모두 물음표로 끝났다.
   JJ 문법: `{사실 + 진짜 숫자}… {그런데|언제} {질문}?` + 필요하면 `| {주제 라벨}`
   - `내일부터 밤 8시까지 주식 거래 시작… 그런데 종가는 왜 3시 반? | 애프터마켓`
   - `AMD는 8% 뛰었는데 엔비디아는 5% 급락… 월요일 삼성·SK하이닉스는?`
   따라오는 세부 규칙 셋:
   - **기호로 압축하지 않는다.** `AMD +8% vs 엔비디아 -5%` → `AMD는 8% 뛰었는데 엔비디아는 5% 급락`. 피드에서 읽히는 건 문장이지 표가 아니다.
   - **질문에 '언제'를 붙인다.** `삼성·SK하이닉스는?` → `월요일 삼성·SK하이닉스는?` 시청자가 이 정보를 언제 쓰는지가 제목에 있어야 한다.
   - **무엇인지 흐리지 않는다.** `밤 8시까지 거래…` → `밤 8시까지 주식 거래 시작…`
3. **날짜·회차·포맷명을 제목에서 뺀다.** 설명란 첫 줄로 내린다. 단 **주제 라벨은 남긴다** — `| 미국 주식 주간`(포맷)은 빼고 `| 애프터마켓`(주제)은 둔다. 2026-09-13 JJ가 미국 주간편 제목에서 `| 미국 주식 주간`을 직접 지웠다.
   - 현행 `… | 9/11 국장 마감 #005` → 꼬리 전체 삭제
   - 고칠 코드 3곳: `jobs/publish.py` `kr_title_v3` (201행~, `tail` 조립부) / `jobs/narrate_weekly.py` `build_title` (1002~1023행, 모든 후보의 `| {rng} 주간 결산`) / `jobs/narrate_us_weekly.py` `TITLE` (1301행, `| {rng} 미국 주간`)
   - **캐비엇**: 날짜 효과의 근거는 n=2 비교(60.3만 vs 6.3만)이고 연령 보정을 거치지 않았다. 비용이 0이라 먼저 바꾸되 **2주 A/B로 확인한다.**
4. **제목 명사구 = 첫 문장 명사구.** 제목의 숫자 토큰이 s0 첫 120자에 전부 들어 있어야 한다(검사 추가 대상). 지금은 `publish.py`가 제목을, `narrate_aplus.py`가 s0를 따로 만들어 어긋날 수 있는 구조다.
5. **일요일 제목에 한국 토큰 1개 이상.**
   - 2026-09-13 실제 채택본(JJ): **`AMD는 8% 뛰었는데 엔비디아는 5% 급락… 월요일 삼성·SK하이닉스는?`** — 미국 사실 두 개를 말로 풀고, 한국 토큰을 질문 자리에 놓고, 포맷 꼬리를 뺐다.
6. **'진짜 이유'류 어휘 금지.** 리프트가 최대 1.64x로 크지만, 우리 본문 상한이 "시점이 겹칩니다"라 제목이 본문보다 센 낚시가 된다. 대신 쓰는 명사구: **받아 간 곳 / 혼자 반대였던 곳 / 따로 있었습니다 / 멈추지 않은 곳**.
7. **'다음 X' 프레임 금지**("706% 오른 ○○ 다음"). 실질이 종목 추천이다.

## 9. 화면 규칙

1. **말 한 마디마다 화면이 반응한다.** 문장 하나에 카드 하나. 사슬(T15)은 칸마다 카드 하나씩 바뀌도록 설계한다. 대본을 고쳤으면 **렌더 뒤 장면별 프레임을 뽑아 눈으로 대조한다**(`qa_script.py frames`).
2. **색 규칙 고정**: 빨강 = 상승·순매수 / 파랑 = 하락·순매도 / 노랑 = 질문.
3. **질문 카드에는 질문만.** 노란 카드에 숫자·표를 같이 올리지 않는다. 질문이 화면을 맡으므로 **"이게 왜 중요하냐면" 같은 도입어는 말로 하지 않는다**(기능 중복 + 블록당 5초 낭비).
4. **출처는 문장이 아니라 라벨.** 훅 카드 하단 고정: `자료: 장 마감 직후 수급 원자료 · 16:30 집계`.
5. **마무리 화면**: 결론 카드부터 그래프·표를 전부 내리고 **문장 카드 한 장.** 끝 멘트 5.1초는 채널명 + 다음 업로드 시간 한 장.
6. **비유는 화면에 그려지는 것까지만.** '가게·배·조각'처럼 카드로 그릴 수 있는 것만 쓴다. '혈관·설계도' 같은 몸/사물 비유는 그릴 데이터가 없으므로 쓰지 않는다. **편당 1개, 처음 나오는 개념을 풀 때만.**
7. **썸네일은 훅 프레임.** 큰 글자 2~3줄 질문. 표·고지 카드 프레임은 썸네일로 쓰지 않는다.
9. **한 화면이 8초를 넘기지 않는다.** 말이 이어지는데 화면 요소가 하나도 새로 켜지지 않는 구간이 8초 이상이면 그 장면은 다시 설계한다. 2026-09-13 JJ 지적("0:37~1:14 동안 자료가 1개로 퉁치고 있어")이 여기서 나왔다. 판단 기준 블록(§3-1 s5-③)은 `1일 그날 사정 / 2일 아직 이르다 / 3일~ 자리 잡는 흐름` 눈금으로 그리고, 오늘 위치는 노랑, 기준선은 그 말을 할 때 초록으로 켠다(`ScenesV4.tsx` S5V4).
10. **장면을 잘게 쪼개지 않는다.** `qa_script.py`가 장면당 0.4초 이음새를 길이에 더하므로 장면 수를 늘리면 예산이 준다. 결론·구독·끝 멘트 사이에 무음을 두지 말고 한 장면으로 붙인다.

## 10. 하면 안 되는 것 (경제사냥꾼에서 배우지 말 것)

| 하지 말 것 | 이유 |
|---|---|
| **반말 페르소나** ("~했어", "님들", "~거든", "~잖아") | 화자가 edge-tts다. 반말 친밀감은 재현이 안 되고 불쾌해진다. 합니다체 고정 |
| **1인칭 자격 증명** ("제가 밤새 뜯어왔습니다") | '저는·저희'는 금지어. 주어를 지우면 누가 셌는지 빈 이상한 문장이 되고 매일 반복하면 AI 티 나는 상투구가 된다 |
| **공포 마케팅 / 손실 회피** ("모르면 크게 물립니다") | 금지어에 걸리고, 공포로 클릭을 사는 방식은 우리 정체성과 충돌한다 |
| **정보 비대칭 프레임** ("월가만 알고 우리는 모른다") | 우리가 파는 건 '아는 집단 vs 모르는 집단'이 아니라 **오늘 세어 본 숫자**다 |
| **추천성 표현** (목표가, 콕 집은 종목, 다음 X) | 금지어 검사를 우회해도 실질이 추천이다 |
| **권위자 이름 걸기** (젠슨황·버핏·파월) | 발언은 누구나 받아쓴다. 그 경기장에선 구독자 많은 쪽이 이긴다. 예외: 발언 다음 날 **우리 수급으로 검증**할 때만, 그때도 제목 주어는 수급 주체 |
| **3분 초과** | 쇼츠 피드에서 빠진다. 유통이 끊기면 내용은 의미가 없다 |
| **고정 4칸 훅 템플릿** | 우리 훅은 매일 같은 데이터 모양에서 자동 생성된다. 칸 순서까지 고정하면 매일 거의 같은 문장이 나온다 — JJ가 강하게 경고한 상태 |
| **CTA 스택** (좋아요+알림+댓글+구독) | 106자 = 14.7초 = 평일의 12%. 우리는 구독 한 줄 26자만 |
| **롱폼 로드맵** ("오늘은 세 가지를 봅니다") | 3분에서 목차는 블록 하나 반. 질문 사슬이 이미 견인 역할을 한다 — 목차를 깔면 그 견인력을 스스로 없앤다 |
| **확장 연결어** ("게다가·심지어·여기에") | 상위 0.19/분 vs 하위 0.41/분. 블록 경계를 흐려 나열형 리캡이 된다 |
| **메커니즘 도입어** ("이게 왜 중요하냐면") | 노란 질문 카드와 기능이 중복된다 |
| **결론-CTA 연결어미 흡수** ("~라는 거 꼭 기억하고") | 채널 스스로 버리는 중(하위 80% vs 상위 30%). 결론 문장을 늘려 한 줄 압축을 막는다 |
| **통화 환산** ("우리 돈으로 506조원") | 단위만 바꾼 재진술. 배수 앵커가 같은 자리에서 더 많은 일을 한다 |
| **화면 지시어** ("보시면") | 상위 0.00/분, 하위 0.10/분의 저품질 지문. 우리는 화면이 말을 따라온다 |
| **지수 목표 레벨** ("6,950 지키면 7,050 열린다") | `assist_ok`는 통과해도 우리 입에서 나오면 단정으로 읽힌다. 수급 연속일수로 바꾼다 |
| **맞은 날만 훅으로** | ledger의 존재 이유(틀린 것도 남긴다)를 갉아먹는다. 끊긴 날도 같은 형식으로 훅이 된다 |
| **매일 같은 문장·같은 각도** | AI 티의 정체. 전환 id·각도 id·훅 id를 기록하고 회전시킨다 |

## 11. 제작 체크리스트 (JJ에게 보내기 전)

`python jobs/qa_script.py script --kind {day|kr|us} --date YYYYMMDD` 를 먼저 돌린다. 그다음 아래를 손으로 확인한다.

### A. 길이
- [ ] 평일 총 760~800자 / 주말 1,150~1,230자
- [ ] **계산이 아니라 실측**: `--stage=tts` 로그의 '총 N초'가 **172초 이하**(평일·주말 공통). 하한은 없다
- [ ] 훅 45~60자, 첫 물음표 평일 ≤42자(≤6초)·주말 ≤43자
- [ ] 평일 장면은 **s0·s2·s3·s5·s6 다섯 개**(s1·s4를 쓰면 화면이 없다)
- [ ] 마무리 = s5 ≤245자 + s6 37자 (주말 ≤215자)

### B. 금지어·어조
- [ ] `checks/forbidden.py find()` 무반응 (대본 전문 + 제목 + 쓰레드 각각)
- [ ] 홑낱말 '매수/매도' 없음 → 순매수·순매도·매입·매도세
- [ ] 인과 단정어 없음 → 시점 겹침·같은 방향·쪽에 가까워
- [ ] 어시스트 문장에 **조건절('~면')** 있고 **종목명 없음** (`assist_ok` 통과)
- [ ] 합니다체 일관 (해요체 '~하세요', 반말 '~했죠' 없음)
- [ ] '비중·주목·확실히·진입' 없음

### C. 화면 대조
- [ ] 렌더 뒤 `qa_script.py frames`로 장면별 프레임 추출 → 말과 카드가 1:1인지 눈으로 확인
- [ ] 질문 문장 구간에 노란 카드 한 장만(숫자·표 없음)
- [ ] 색 규칙(빨강 순매수 / 파랑 순매도 / 노랑 질문) 어긋난 카드 없음
- [ ] 훅 카드 하단 출처 라벨 있음
- [ ] 마무리 구간에 그래프·표 없음(문장 카드만)
- [ ] 썸네일이 훅 프레임(큰 글자 2~3줄 질문)

### D. 뼈대 반복
- [ ] 직전 3편과 문장 뼈대 겹침 2개 미만 (`qa_script.mask()`; 끝 멘트·구독 두 줄 제외)
- [ ] `hook_id`(H01~H06)가 최근 3편과 다름
- [ ] `angle_id`(A01~A09)가 최근 5영업일과 다름
- [ ] `devices`(T01~T22)에서 최근 3편 사용 id 제외했고, 한 편 안에 중복 없음
- [ ] 요약 선언문("한 줄로 줄이면")이 이번 주 3회 이하

### E. 숫자 검산
- [ ] 1,000자당 숫자 11개 이하 (평일 총 9개 이하)
- [ ] 모든 수급 금액에 비교 앵커 있음 (5일평균 배수 / 전일 대비 / 20거래일 순위)
- [ ] 배수 표현 1~2회 있음, 비교 기준이 **같은 문장 안**에 명시됨
- [ ] 숫자 문장의 50% 이상이 3문장 안에 '뜻/셈' 문장으로 이어짐
- [ ] 조 단위에 소수점 없음 (9.9조 ❌ → 9조 9천억 ✅), %·달러 소수는 유지
- [ ] 마무리 174자 안 숫자 최대 1개이고 **앞에서 나온 숫자의 재언급**
- [ ] 원자료 대비 금액·방향·날짜 재확인 (특히 주체별 합계와 합산 재진술의 덧셈)

### F. 구조
- [ ] 훅 질문이 다음 장면 첫 문장에서 바로 답을 받는다 (요약 반복 없음)
- [ ] 전개부 질문 = 블록 경계 2개, 질문 문장에 숫자 없음
- [ ] 재정의('A가 아니라 B') 2~3회
- [ ] 각 블록이 '그래서 무슨 뜻' 한 줄로 닫힘
- [ ] 마무리 확인점이 **정확히 1개**이고 ledger에 기록됨
- [ ] 양방향 조건 분기: 평일은 주 1회(금), 주말은 항상 두 갈래 다
- [ ] 일요일편: 제목에 한국 토큰 1개 이상 + uw0 마지막에 국장 연결 예고
- [ ] 제목에 날짜·회차 없음, 물음표 없음, 주어가 수급 주체
- [ ] 제목 숫자 토큰이 첫 장면 120자 안에 전부 들어 있음
