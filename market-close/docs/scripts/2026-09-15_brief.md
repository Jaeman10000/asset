# 9/15(화) 국장 마감 — 수급 브리핑 형식 (JJ 2026-09-15 밤 지시)

순서: ① 코스피 수급 나열 → ② 코스닥 수급 + 지수 등락 → ③ 돈이 빠진 곳·정체된 곳 → ④ 돈이 들어온 곳(업종 안 주체별) → ⑤ 대장주 1 + 최대 상승 1, 주체별 매매 → ⑥ 관련 뉴스와 맞물렸는지 → ⑦ 내일 볼 포인트 + 시그니처.
숫자는 키움 943종목 합산(정규장 체결 기준)이고 KRX 마감 집계와 일치. 종목 수급은 키움 종목별 투자자(억).

---

**① 코스피 수급** — 화면: 막대 4개 `외국인 −1.57조 / 기관 −0.90조 / 개인 +0.83조 / 기타법인 +1.64조`, 기타법인 막대 아래 `자사주 99%`
- 오늘 코스피 수급입니다. 외국인 1조 5,700억 순매도, 닷새째입니다.
- 기관은 9,000억을 팔았습니다. 개인은 8,300억을 샀습니다.
- 가장 많이 산 쪽은 기타법인, 1조 6,400억입니다. 그중 99%가 삼성전자와 SK하이닉스 자사주입니다.

**② 코스닥 수급 + 지수** — 화면: 코스닥 막대 3개 `외국인 +241억 / 기관 +1,107억 / 개인 −1,398억` → 지수 카드 `코스피 6,627.26 ▼0.85%` `코스닥 812.41 ▲0.70%`
- 코스닥은 반대였습니다. 외국인 240억, 기관 1,100억 순매수, 개인은 1,400억 순매도입니다.
- 지수는 코스피 0.85% 하락, 코스닥 0.70% 상승.
- 코스피는 외국인과 기관이 빼고 개인과 자사주가 받은 날, 코스닥은 외국인과 기관이 사고 개인이 판 날입니다.

**③ 돈이 빠진 곳·정체된 곳** — 화면: 업종 유출 막대 `반도체 −2.04조 / 조선 −0.13조 / 원전 −0.07조 / 방산 −0.07조` → 반도체 막대 옆에 `외국인 −1.34조 · 기관 −0.71조` → 종목 칩 `삼성전자 −0.2% / SK하이닉스 −0.4%` + `자사주 +1.63조`
- 돈이 빠진 곳은 반도체입니다. 외국인 1조 3,400억, 기관 7,100억, 합쳐 2조 400억이 나갔습니다. 닷새째 나가는 중이고, 어제 3조 8,300억보다는 줄었습니다.
- 그런데 삼성전자는 0.2%, SK하이닉스는 0.4% 내리는 데 그쳤습니다. 두 회사 자사주 1조 6,300억이 그 물량을 받아 값을 붙들고 있습니다. 돈이 정체된 자리는 여기입니다.
- 조선에서 1,300억, 방산과 원전에서 700억씩도 빠졌습니다.

**④ 돈이 들어온 곳** — 화면: 유입 막대 `이차전지 +937억 / 로봇 +376억 / 건설 +361억 / 철강 +266억`, 이차전지·로봇 막대는 `외국인 / 기관` 두 색으로 나눔
- 들어온 곳은 이차전지와 로봇입니다.
- 이차전지에 외국인 480억, 기관 460억, 합쳐 940억이 들어왔습니다. LG에너지솔루션, 삼성SDI, 포스코퓨처엠, 에코프로비엠 네 종목 모두 순매수였고 업종은 3.1% 올랐습니다.
- 로봇에는 외국인 260억, 기관 120억, 합쳐 380억이 들어왔고 5.1% 올랐습니다.
- 반도체에서 나간 2조 400억에 견주면 두 곳에 들어온 돈은 1,300억, 16분의 1입니다. 옮겨간 돈보다 나간 돈이 훨씬 큽니다.

**⑤ 종목 둘** — 화면: 종목 카드 2장, 각각 등락률 크게 + `외국인 / 기관 / 개인` 세 줄
- 이차전지 대장주 LG에너지솔루션은 3.98% 올랐습니다. 기관이 410억을 샀고, 외국인은 8억, 개인은 320억을 팔았습니다. 기관이 밀어 올린 상승입니다.
- 가장 많이 오른 종목은 로봇 부품 삼현, 상한가 29.8%입니다. 외국인 13억, 기관 26억 순매수, 개인 37억 순매도. 거래대금 548억짜리 종목이라 큰손 돈은 작았습니다.

**⑥ 뉴스와 맞물렸나** — 화면: 뉴스 카드 2장(제목 한 줄 + 출처·날짜), 아래 판정 줄 `이차전지: 뉴스 + 외국인·기관 동반` `로봇: 뉴스 먼저, 큰손 돈은 작음`
- 뉴스는 두 갈래였습니다. 이차전지는 미국 교통부가 포드에 중국 CATL과의 배터리 협력을 정리하라고 보낸 서한이 다시 부각됐습니다.
- 로봇은 정부가 제조업 AI 전환을 전국으로 넓히는 콘퍼런스를 열었고, 미국의 중국산 로봇 규제 강화 움직임이 겹쳤습니다.
- 이차전지는 뉴스와 외국인·기관 순매수가 같이 갔습니다. 로봇은 뉴스가 값을 먼저 올렸고, 들어온 큰손 돈은 380억으로 작았습니다.

**⑦ 내일 볼 포인트 + 시그니처** — 화면: 번호 3줄 → `목 새벽 3시 FOMC · 인상 92%` → `저녁 8시까지 애프터마켓` → 로고 `저녁 5시`
- 내일 볼 포인트는 셋입니다. 외국인 순매도가 엿새째 이어지는지. 이차전지에 외국인·기관 돈이 이틀째 들어오는지. 그리고 목요일 새벽 3시 미국 금리 결정, 인상 확률 92%입니다.
- 정규장이 끝나도 저녁 8시까지 애프터마켓에서 거래됩니다.
- 누가샀나였습니다. 국장 마감은 내일부터 매일 저녁 5시에 올라옵니다.
