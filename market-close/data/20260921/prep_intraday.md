## 오늘의 뼈대 — "지수는 올랐는데 내 계좌는"

| 숫자 | 값 | 출처 |
|---|---|---|
| 코스피 | 장중 7,007.10까지 올라 **8거래일 만에 7,000선 터치** 뒤 다시 내줌 | 뉴스핌 09:25 |
| 상승률 | **0.99% → "1%"로 말한다** | 파이낸셜뉴스 10:05 |
| **대형주 / 중형주 / 소형주** | **+1.37% / −0.48% / −0.42%** | 파이낸셜뉴스 10:06 |
| 오른 종목 / 내린 종목 | **321개 / 530개** | 오전 집계 |

**→ 이것이 오늘의 성격이다.** 지수는 1% 올랐는데 내린 종목이 더 많다. 반도체가 혼자 끌었다.
시청자 속마음("지수 올랐다는데 내 계좌는 왜")을 먼저 말하고 '그런데'로 잇는 자리.

**⚠ 종가로 반드시 다시 셀 것** — 오후 들어 코스닥이 상승 전환했으므로 중·소형주가 플러스로 돌아섰을 수 있다.

> ⚠ **"정부가 동결했다"고 말하면 안 된다.** 발표 주체는 한국전력이고, 오늘 기사·공지 어디에도 산업부·전기위원회 명의 발표나 심의 절차 언급이 없다.
> ⚠ **"18분기째 동결"은 연료비조정단가가 상한에 붙어 있다는 뜻**이지 전기요금 전체가 18분기 동안 안 올랐다는 뜻이 아니다.
> ⚠ 7.3원과 5원의 차이를 '분기당 얼마 손해'로 환산하지 말 것 — 기사가 환산하지 않았다.

## 조사에서 걸러낸 것 (내가 그냥 썼으면 틀렸을 것)

| 쓸 뻔한 말 | 실제 |
|---|---|
| "코스피가 0.9% 올랐다" | **0.99% → 1%**. 0.9%로 쓰면 한 단계 낮춰 말하는 것 |
| "9시 23분에 7,002.30까지 올랐다" | 9시 23분은 **이미 7,000선을 내준 뒤**(6,961.33). 7,002.30은 그보다 앞선 장 초반 고점 |
| "정부가 4분기 전기요금을 동결했다" | **한국전력 공지**다. 정부 명의 발표가 아니다 |
| "한전 상반기 영업이익 13조 4,905억" | 한전 공식 발표와 어긋남 — **쓰지 않는다** |
| "회동 결과는 공개되지 않았다" | 베선트가 **직접 브리핑**했다 |
