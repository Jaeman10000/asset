## 쓰는 법

- **썸네일:** Gemini 에 장면 + 정본 시트를 같이 주고 "인물 크기로 장면 안에" → 받은 그림에 `SceneThumb`(render/src/v4/SceneThumb.tsx)로 글자만 얹는다. 우리 컷을 장면 위에 붙이면 어색하다(JJ). 규칙은 `docs/SCRIPT_GUIDE.md §17-0`.
- **영상 안:** 투명 컷을 장면 한쪽에 잠깐씩 띄운다(제안 — §17-0 '영상 안 출연').
- 새 포즈가 필요하면 정본 시트를 첨부해 Gemini 에 한 장씩 요청하고, 여기 `sheets/` 에 원본을 넣고 `cutouts/` 로 오린다.
